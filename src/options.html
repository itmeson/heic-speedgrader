HEIC Viewer for Canvas SpeedGrader

Shows iPhone HEIC photo submissions inside SpeedGrader.

Your Canvas address

If your school's Canvas address ends in instructure.com (for example myschool.instructure.com), you're all set. Nothing to do here.

If your school uses its own address (for example canvas.myschool.org), add it below. Chrome will ask you to allow the extension on that site.

Added addresses

  • None yet.

After adding an address, reload any open Canvas tabs.

How to use it

  1. Open SpeedGrader on an assignment.
  2. When a student submitted a HEIC photo, it appears in the preview area, or in a green HEIC image box at the bottom-left. Click the file name to view it.
  3. Use Fit, −/+, ⟳ (rotate) and Save JPG in the viewer's toolbar.

Privacy

Images are downloaded from Canvas with your existing login and decoded on this computer. The extension doesn't send data anywhere, doesn't store anything, and doesn't need a Canvas API token.
