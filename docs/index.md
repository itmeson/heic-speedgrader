# HEIC Viewer for Canvas SpeedGrader

A Chrome extension that shows iPhone HEIC/HEIF photo submissions inside
Canvas SpeedGrader. Images are decoded on your own computer; the extension
has no server and sends nothing to the developer.

- [Privacy policy](privacy)
- [Source code](https://github.com/itmeson/heic-speedgrader)
- [Report a problem](https://github.com/itmeson/heic-speedgrader/issues) –
  please don't post student work, names, screenshots of real courses, or
  Canvas file links.
- [Security policy](https://github.com/itmeson/heic-speedgrader/security/policy)

## Try it without Canvas

1. Install the extension.
2. Click its toolbar icon to open the Options page, then choose
   **Test the decoder with a HEIC file from your computer**.
3. Pick a HEIC photo, or download this synthetic
   [sample worksheet photo](samples/sample-worksheet.heic).
